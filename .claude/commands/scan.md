Scan this repository and regenerate REPO_MAP.md with the current state of the codebase. This is the `/scan` command — run it whenever the project structure changes significantly.

## Steps to Execute

**1. Map directory structure**
Use Glob to map the full project tree (3 levels deep). Exclude: `node_modules`, `.git`, `.next`, `dist`, `build`, `coverage`, `.turbo`, `out`. Count files per directory.

**2. Inventory all package.json files**
Read root `package.json` and all workspace packages (`apps/*/package.json`, `packages/*/package.json`). For each, extract:
- All dependencies + versions
- All devDependencies + versions  
- Scripts defined
- Package name and version

**3. Detect config files**
Check for presence of: `tsconfig.json` (is strict mode on?), `.eslintrc` / `eslint.config.*`, `.prettierrc` / `prettier.config.*`, `tailwind.config.*`, `next.config.*`, `nest-cli.json`, `docker-compose*.yml`, `.env.example`, `pnpm-workspace.yaml`, `vitest.config.*`, `playwright.config.*`

**4. Map frontend routes**
If `apps/web/app/` exists, list all routes (map directory names, note layout.tsx / page.tsx / loading.tsx / error.tsx presence per route).

**5. Map backend domains**
If `apps/api/src/modules/` exists, list all NestJS modules. For each module check for: `*.module.ts`, `*.controller.ts`, `*.service.ts`, `*.repository.ts`, `*.entity.ts` / schema, `dto/` directory.

**6. Map shared packages**
If `packages/shared/` exists, list exported types, event contracts, and Zod schemas.

**7. Identify gaps vs ADR decisions**
Cross-reference what exists against the decisions in ADR-001-to-006.md. Flag anything promised in an ADR that isn't yet present.

**8. Check design system integration**
Is `design-system/MASTER.md` referenced in tailwind.config? Are design tokens exported to `apps/web/src/lib/design-tokens.ts`? Are Ignite fonts loaded in `layout.tsx`?


## After Writing

Report a 3-bullet summary:
- What's new since last scan (or what was found on first scan)
- Top 3 gaps to address next
- Estimated scaffold effort if monorepo hasn't been created yet
